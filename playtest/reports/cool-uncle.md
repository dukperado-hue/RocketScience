# Playtest report — ลุงเจ (cool-uncle) · mobile 390x844 + desktop 1366x768 · 2026-10-19

Build: v0.22.2 (`softlaunch`) · Session folder: `playtest/runs/cool-uncle/`
เล่นจริงประมาณ 20 นาที (มือถือ 11 นาที + desktop 8.4 นาที ตาม `minutesPlayed`) ไม่ครบ 25 เพราะการบินแม้ที่ 10× ก็กินเวลาจริงเยอะ แล้วเนื้อหาซ้ำ

## 5 นาทีแรก
เปิดมา (มือถือ) เจอการ์ดหน้าปกรูปนากถูกมัดกับเก้าอี้ ล้อมด้วยพลุ แมว เป็ด คาปิบารา ลุงขำตั้งแต่ภาพแรก (`playtest/runs/cool-uncle/001-mobile-first.png`) มีคำเตือนสีเหลืองเรื่องปล่อยโคมใกล้สนามบิน ทั้งอังกฤษและไทย อยู่บนการ์ดเลย อ่านชัด ลุงกด "Watch the legend (10 s)" เป็นหนังสั้น 10 วินาที ภาพสวยน่ารัก แต่บนมือถือเป็นแถบแคบ ๆ กลางจอดำ (`002-mobile-legend1.png`) พอจบก็ถูกโยนมาหน้า Factory ที่ว่างเปล่า ไม่มีใครบอกว่าต้องทำอะไรต่อ ต้องเลื่อนลงไปหาลิสต์ชิ้นส่วนเอง

เก้าอี้ "Up! Wan Hu's lantern chair" ถูกล็อก (🔒 Mission 1) ลุงไปแท็บ Missions เห็นปุ่ม Campaign/Sandbox ลองกด Sandbox ข้อความบอกว่า "ทุกชิ้นปลดล็อก เที่ยวบินไม่บันทึก" ก็ได้เก้าอี้เลย (`005-mobile-sandbox.png`) กลับ Factory เลื่อนลงไปกดพรีเซ็ต หน้าจอเลื่อนไปตำแหน่งแปลก ๆ ต้องเลื่อนกลับขึ้นบนถึงจะเห็นโคม 400 ดวงเรียงเป็นแท่งตึก เห็นแล้วขำมาก (`007-mobile-built.png`) แล้วไปแท็บ Launch กดปุ่มส้ม IGNITION

## จุดที่งง
- บนมือถือหลัง "Start building" แทบไม่มีคำแนะนำว่าต้องหยิบอะไร เห็นแต่ตารางว่าง (`003-mobile-legend2.png`) พรีเซ็ตอยู่ลึกใต้ลิสต์ชิ้นส่วนยาว ๆ
- ไม่รู้ว่าต้องไป Missions > Sandbox ถึงจะได้เก้าอี้ Up! ล็อกเขียนว่า "Mission 1" ซึ่งฟังเหมือนต้องทำภารกิจก่อน ไม่มีบอกว่ามี Sandbox ลุงลองเดาเอง
- ปุ่มเร่งเวลา 1×/2×/4×/10× และ Map/Cam อยู่ในแถบปุ่มที่เลื่อนข้าง ตอนแรกมองไม่เห็นเลย (ถูกตัดที่ "Assist:" `008-mobile-launch.png`) ลุงต้องไล่ดูปุ่มด้วย eval หลังรอจนเบื่อ
- ปุ่มเริ่มใหม่ในหน้าสรุป: มือถือเขียน "Fly again" แต่ desktop เขียน "บินอีกครั้ง / Retry Flight / R" ภาษาไม่ตรงกัน (`018-mobile-fly8.png` เทียบ `034-desktop-d6.png`)
- (เรื่อง harness) กดปุ่ม IGNITION ด้วย selector ข้อความไม่ได้ เพราะไปชนข้อความซ่อน "Press Space or IGNITION" ต้องกดพิกัดเอง ไม่นับเป็นปัญหาผู้เล่นจริง

### BUG-2 · มือถือ: เรดาร์ทับการ์ด Launch site และสรุปผลทับแผงข้อมูล

**7 / 10** — ภาพกับมุกขำจริงและ disclaimer ชัด แต่ทางเข้ามือใหม่งง การบินยาวเกินความอดทนคนไม่ใช่เกมเมอร์ และไม่มีปุ่มแชร์เลย

## ข้อเสนอ 3 ข้อ
1. **ทำให้แชร์ง่าย**: ตอนนี้ไม่มีปุ่มแชร์/บันทึกภาพ/คลิป/ลิงก์ในหน้า Landed/Crashed (ค้นข้อความ share/แชร์/copy/download/record ในหน้าไม่เจอ) เพิ่มปุ่ม "แชร์ลงไลน์" สร้างการ์ดภาพสรุป (ภาพโคมตึก + มุกซอมบี้ตอนจบ + ค่าปรับ + disclaimer + ชื่อเกม) ใช้ Web Share API บนมือถือ จะแชร์ได้ในสามแตะ
2. **เร่งเวลาและตัดช่วงน่าเบื่อ**: ใส่ปุ่ม "ข้ามไปจบ/ช็อตเด่น" ให้ปุ่มความเร็วเห็นชัดบนมือถือ และทำปุ่มลัดเก้าอี้ Up! (บอกว่าเล่นใน Sandbox ได้) ที่หน้าแรกหรือ Factory
3. **จัดเลย์เอาต์มือถือใหม่**: ป้ายค่าส่วนใหญ่ 11px (บน desktop นับข้อความต่ำกว่า 12px ได้ 87 จุด; บนมือถือ Altitude/Velocity ฯลฯ 11px บางข้อความ 10.5px) สำหรับสายตายาวเล็กไป ควรอย่างน้อย 14px แก้การทับของเรดาร์/Launch site/ป๊อปอัปสรุป และนำ flight log + milestone (Capybara) มาแสดงบนมือถือด้วย

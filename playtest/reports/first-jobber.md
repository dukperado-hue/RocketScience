# Playtest report — first-jobber ("ปั้น") · mobile (390x844 touch) · 2026-10-19

Build: v0.22.2 (`softlaunch`) · Session folder: `playtest/runs/first-jobber/`

หมายเหตุก่อนอ่าน: เวลาเล่นรวมตาม `minutesPlayed` ประมาณ 7 นาที (session 1+2 = 5.7 นาที, session 3 private = 1.2 นาที) เพราะใช้ warp 10x ตลอด ไม่ถึง 25 นาทีตามงบ แต่เล่นจบ M1, M2 และไปถึงหน้า M2.5 แล้ว (ไม่ได้ลองเล่น M2.5)

## 5 นาทีแรก
เปิดเกมบนมือถือ `perf` บอก load 1.5 s (DOMContentLoaded 192 ms) ถือว่าเร็วมาก (เป็น localhost นะ เน็ตจริงบนรถไฟฟ้าไม่รู้) เจอการ์ด "From Wan Hu's Chair to Outer Space" รูปน่ารัก ปุ่ม "Watch the legend (10 s)" กับ "Start building" ชอบที่ให้ข้ามได้ แต่การ์ดนี้กับกล่องเตือน (disclaimer สีเหลือง สองภาษา) กินเกือบเต็มจอ (`001-mobile-start.png`)

กด Start building → `audio` เปลี่ยนจาก `not-created` เป็น `running` ทันทีตั้งแต่แตะแรก (ดีมาก ไม่ต้องหาปุ่มเปิดเสียง) แล้วเจอกริดเปล่าๆ ไม่มีบอกว่าต้องทำอะไร ต้องไปกดแท็บ Missions ถึงรู้ว่า M1 คือ "ปล่อยโคมลอยจากเกาะพะงัน แล้วให้ลมพาเข้าน่านฟ้าสมุย" (`003-mobile-missions.png`) แล้วต้อง "เลื่อนหน้าลงไป" ถึงเจอรายการชิ้นส่วน/Blueprint "Khom loi" เพราะบนมือถือกริดกินครึ่งบน รายการชิ้นส่วนยาวเกือบ 4,300 px (`scrollHeight` 4353) กดแบบพิมพ์ Blueprint แล้ว ปุ่ม "Roll out to the pad" อยู่ล่างสุดของหน้าห่างจากกริดเป็นพันพิกเซล ฉันหาไม่เจอด้วยตา ต้องใช้ selector ช่วย (คนจริงต้องเลื่อนนิ้วยาวมาก)

พอถึงหน้า Launch ได้กดแตะ IGNITION → โคมลอยขึ้น เร่ง 10x แล้ว ~12 วินาทีจริง M1 สำเร็จ (log: "MISSION 1 COMPLETE" ที่ T+43) เร็ว ตรงใจคนขี้เบื่อ แต่ "ไม่มีการ์ดฉลอง/บอกว่าผ่านภารกิจ" บนหน้าจอระหว่างบิน ฉันรู้จาก `log` กับแท็บ Missions เท่านั้น (ดู BUG-3)

## จุดที่งง
- เข้าเกมมาไม่มีอะไรบอกว่าต้องทำอะไร ต้องไปอ่านแท็บ Missions เอง มีแค่แถบ "Next: Mission 1 …›" ที่อยู่ใต้ตัวแก้ไขต้องเลื่อนลงถึงจะเห็น (`002-mobile-factory.png`)
- ปุ่มสร้างจรวด/Blueprint เรียงอยู่ท้ายหน้ายาว ปุ่ม "Roll out to the pad" ลึกสุดหน้า (4,295 px) งงว่าจะไปหน้ายิงยังไงถ้าไม่เห็นปุ่ม จริงๆ แท็บ "Launch" ด้านบนก็กดได้ แต่ไม่รู้ว่ากดได้เลยไหม
- M2: Blueprint "Bang Fai" ล็อกด้วยข้อความ "Craft slow powder first" ต้องไปที่ "Mixing bench" ซึ่งซ่อนอยู่ใต้ส่วน "Tier 3-4 Space Age Coming Soon" และ "Test payloads" ใกล้ท้ายหน้า (`015-mobile-mix.png`) ฉันต้องรู้เอง ว่าต้องเปิดโต๊ะผสมเชื้อเพลิง
- โต๊ะผสมเชื้อเพลิงอธิบายดีมาก (กดแล้วบอก "That makes slow powder", "No fuel…" `019-mobile-slow.png`) แต่ "Stir on the beat" เป็นมินิเกมจังหวะ ฉันกดแบบเดาๆ ได้ quality 30% "Uneven; expect misfires" (`022-mobile-stirred.png`) ไม่รู้ว่าจังหวะคืออะไร (ไม่มีเสียง/ภาพนำจังหวะที่เห็นชัด มีแค่จุดกลม 12 จุด) ไม่รู้ว่า quality ต่ำกระทบอะไร
- แผง "Launch Site" บนมือถือโดนการ์ด CAPCOM (ซอมบี้) บัง: สไลเดอร์ Wind โผล่ครึ่งเดียว (`024-mobile-launch3.png`) กว่าจะตั้งลม 0 ได้ต้องรอการ์ดจางเอง แล้วลากโดยเดาตำแหน่ง
- แถบปุ่มด้านล่างตอนยิง: ปุ่ม "Chute" กับ "Hold" ชนกัน และ "Assist:" ถูกตัดขอบ (`006-mobile-launch.png`, `007-mobile-flight.png`)

### BUG-1 · ปุ่มควบคุมการบินล้นจอ/ซ้อนกัน บนมือถือ
- ขั้นตอน reproduce:
  1. start --viewport mobile, Start building, โหลด khom-loi, Roll out
  2. ดูแถบปุ่มล่างสุดบนหน้า Launch
- ที่เกิดขึ้น / ที่คาดไว้: ปุ่ม "Chute" กับ "Hold" ซ้อนกัน, "Assist:" ถูกตัด, ปุ่มความเร็ว (1x/2x/4x/10x), Map, Cam, เสียง, ซูม, "again" (บินอีกครั้ง), "back" อยู่นอกจอไปทางขวา (x 655–1095 จากจอกว้าง 390) ต้องเลื่อนแถบ ไม่มีสัญลักษณ์บอกว่าเลื่อนได้ ปุ่มกว้างแค่ 36x36 px (ต่ำกว่าเกณฑ์ 44 px ที่แนะนำสำหรับนิ้ว)

## Audio unlock (ตามที่ได้รับมอบหมาย)
- ก่อนแตะ: `audio: not-created`; หลังแตะ "Start building" ครั้งแรก: `running` (`state`) ผ่าน
- หลัง `newtab` กลับเป็น `not-created` ตามที่คาด แล้วเป็น `running` อีกครั้งเมื่อแตะ (ใน session 3 `audio: running` หลังเล่น)
- ปุ่มเปิด-ปิดเสียง (ไอคอนลำโพงในแถบล่าง) หาได้เฉพาะเมื่อเลื่อนแถบไปทางขวา ไม่เห็นบนจอแรกเข้า ฟังเสียงจริงไม่ได้ (harness headless) จึงไม่ทราบว่าเสียงเล่นจริงไหม

## Quick Retry
- หลังตก: ปุ่มใหญ่ "บินอีกครั้ง / Retry Flight" ในการ์ดสรุป ขนาดใหญ่กดง่ายด้วยนิ้วโป้ง (`027-mobile-m2sum2.png`) ผลลัพธ์: กด → กลับไปแท่นทันที (`state`: t=0.0, retryAttempt 2) จรวดเดิมอยู่บนราง ค่ามุมราง/ลมที่ตั้งไว้คงเดิม (`029-mobile-retry1.png`) ไม่มีของเก่าค้าง เร็วมาก
- ปุ่ม R ระหว่างบิน: กด `r` กลางอากาศ → กลับ t=0 ทันที (retryAttempt 3) ใช้ได้ แต่บนมือถือไม่มีแป้นพิมพ์ ปุ่มเทียบเท่าคือ "again" ในแถบล่างที่ต้องเลื่อนแถบไปขวาสุด (BUG-1) ปุ่ม R จริงบนมือถือเลยไม่มี (ไม่ได้ลองกด "again" ตรงๆ)
- คาปิบาร่าทำความสะอาดมีปุ่ม "Skip" (`026-mobile-m2sum.png`) แต่การ์ดสรุปมาหลังภาพนี้ ~10+ วินาทีเกม ถ้าไม่ข้ามต้องรอ

## กลับมาเล่นต่อได้ไหม (newtab ใน session 1/2)
- หลังปิดแท็บตอนกำลังบิน M1: โหลดกลับใน 786 ms (`newtab`), `perf` load 557 ms; ภารกิจเป็น M2, Tier 1 ปลดล็อก, เบลูพริ้นท์ยังอยู่ เซฟใช้ได้ (`010-mobile-after-newtab.png`)
- เที่ยวบินที่กำลังบินหายไป (กลับสู่ Factory) เกมไม่ได้บอกอะไร ถือว่ายอมรับได้
- ผสมดินปืนไว้แล้วหลัง newtab ครั้งที่สอง (M2 → M2.5) ไม่ได้ตรวจว่า propellant ยังอยู่ไหม (ไม่ได้ลอง)

## Private mode (session 3)
- (ก) มีป้ายแจ้งสองภาษา อ่านรู้เรื่อง `storageMemoryOnly: true` (`032-mobile-priv1.png`)
- (ข) เกมไม่พัง เล่น M1 จบใน ~0.6 นาทีได้ปกติ (ผ่านภารกิจ → ภารกิจ 2) `console` ไม่มี error/ pageerror (มีแค่ warning GPU stall ของ WebGL)
- (ค) `newtab` แล้วข้อมูลหายตามคาด: กลับเป็นภารกิจ 1, completed: [] (`035-mobile-priv-after.png`) เกมไม่ได้บอกซ้ำตอนกลับมา (ป้ายอาจโชว์อีกครั้ง ไม่ได้เช็ค) ผู้เล่นที่ไม่รู้จะงงว่าความคืบหน้าหายไปไหน แม้ป้ายตอนแรกบอกไว้แล้ว

## ข้อเสนอ 3 ข้อ
1. แก้แถบปุ่มล่างหน้า Launch สำหรับมือถือ: แบ่งเป็น 2 แถว หรือย่อเป็นเมนู ให้เห็น Warp, Retry (↺), ลำโพงในจอเดียว ปุ่มอย่างน้อย 44x44 px ไม่ซ้อนกัน (BUG-1)
2. ทำปุ่ม "Roll out to the pad"/"Launch" ให้ลอยติดล่างจอ หรือย้ายรายการชิ้นส่วนเป็นแผ่นที่เลื่อนในตัว (bottom sheet) แทนหน้ายาว 4,300 px และเพิ่มคำแนะนำแรกเข้า "เริ่มจากกด Khom loi" ที่เห็นบนจอแรก
3. ให้การ์ด CAPCOM/เรดาร์ย่อหรือแตะปิดได้ ไม่บังแผงตั้งค่า Launch Site และเพิ่มแบนเนอร์ "ภารกิจสำเร็จ!" ชัดๆ ตอนผ่านภารกิจกลางเที่ยวบิน (BUG-2, BUG-3)
